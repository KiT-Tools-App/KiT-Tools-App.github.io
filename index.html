◉

الرئيسية ومراقبة النظام

نظرة مباشرة على موارد ومكوّنات جهازك.

  • GPU والحرارة وذاكرة VRAM

تصفّح البرامج المثبّتة واعثر عليها بسهولة.

يجمع KiT Tools تفاصيل استخدام الجهاز وأدواته اليومية. افتح موقع الملف لعملية، أوقف عملية عند الحاجة، تابع أداء الألعاب، أو شخّص اتصال الشبكة من مكان واحد.

✓قائمة عمليات مع استهلاك CPU وGPU والذاكرة والقرص والشبكة.
✓معلومات عن المعالج والبطاقة الرسومية واللوحة والذاكرة.
✓إعدادات للتحديث التلقائي واللغة والسمة والتشغيل مع Windows.
بعض الإجراءات تغيّر خدمات Windows أو إعدادات الشبكة، وقد تتطلب صلاحيات مسؤول. اختر ما يناسبك قبل تطبيقها.

أسئلة شائعة

قبل أن تبدأ

ما هو KiT Tools؟

تطبيق Windows يضم أدوات لمراقبة موارد الجهاز، إدارة التنزيلات والبرامج، فحص الشبكة، التنظيف ومهام النظام الأخرى.

هل رابط التحميل يحمّل أحدث نسخة؟

نعم. الرابط يشير إلى أصل الملف في أحدث إصدار منشور على GitHub Releases، لذلك يتبع الإصدار الأحدث عند نشره بالاسم نفسه.

أين أجد صفحة البرنامج؟

زر GitHub يفتح مستودع KiT Tools، حيث يمكنك مراجعة معلومات المشروع والإصدارات.

هل كل إجراءات الصيانة تلقائية؟

لا. تختار عناصر التنظيف والإجراءات التي تريد تنفيذها. بعض تغييرات Windows أو الشبكة تتطلب صلاحيات مسؤول، لذلك راجع الاختيارات قبل تطبيقها.

جاهز لاكتشاف KiT Tools؟

حمّل أحدث إصدار أو افتح صفحة المشروع على GitHub لمعرفة المزيد.
